☁️ Google account sync

Sign in with Google to keep your parent settings — API key, PIN, limits, keywords, added videos — saved to your own Google account. Set up once, restore on any device. Stored in your own Google Drive's hidden app storage; no third-party servers.

One-time setup (same Google project as the API key, ~5 min)
  1. console.cloud.google.com → APIs & Services → OAuth consent screen: External, app name "Toon Kids", add your Gmail under Test users
  2. Library → enable the Google Drive API
  3. Credentials → Create credentials → OAuth client ID → Web application
  4. Under Authorized JavaScript origins add: https://toon-kids-raavi.netlify.app
  5. Copy the Client ID (ends in .apps.googleusercontent.com) and paste it below

Device videos, watch history and each child's age stay on each device — only parent settings sync. The backup file works without Google — save it anywhere safe (even WhatsApp it to yourself) and restore on a new device.

🔎 Search YouTube by keyword

To search any keyword ("tom and jerry", "batman", "animals"…) the app needs your own free YouTube API key. It is saved only on this device.

How to get a free key (about 5 minutes)
  1. Open console.cloud.google.com and sign in with your Google account
  2. Create a new project (any name)
  3. Search for "YouTube Data API v3" and press Enable
  4. Go to Credentials → Create credentials → API key
  5. Protect the key: Edit key → Application restrictions → Websites → add this app's address; then API restrictions → YouTube Data API v3 only
  6. Copy the key and paste it here

Results use YouTube's strict Safe Search. You choose what gets added — nothing reaches your child without your tap.
